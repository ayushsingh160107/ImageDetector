# 🔍 TruthLens AI — AI-Generated Image Detector & Explainer

TruthLens AI is a complete, beginner-friendly, Python-native deep learning application that detects whether an uploaded image was captured by a physical camera sensor or generated by artificial intelligence (e.g., Midjourney, Stable Diffusion, DALL-E, FLUX) and provides mathematical visual explanations using **Grad-CAM**.

Built strictly with Python and Streamlit—with **zero separate JavaScript frontends, zero Node.js runtimes, and zero separate REST servers**.

---

## 🚀 Key Features

1. **Single Asset Forensic Detector:**
   - Validates uploaded images against decompression bombs, mime spoofs, and orientation anomalies.
   - Executes PyTorch neural inference with calibrated probability scores.
   - Enforces an uncertainty boundary ($0.40 < P < 0.60$) to classify marginal images as **Inconclusive** instead of making overconfident errors.
2. **Visual Attribution (Grad-CAM & Saliency Maps):**
   - Renders 2D spatial attribution heatmaps showing which pixel regions triggered the model's prediction.
   - Interactive blend opacity slider ($0.0 \to 1.0$), colormap selector (JET vs. VIRIDIS), and multi-view comparative tabs.
3. **Dual Image Comparison Studio:**
   - Upload Image A and Image B independently.
   - Evaluates each image through an independent inference and attribution pipeline.
   - Computes score differentials ($\Delta\text{AI}\%$) and summarizes comparative forensic divergence.
4. **DCGAN Synthetic Image Laboratory:**
   - Deep Convolutional Generative Adversarial Network ($G$ and $D$) implemented in PyTorch.
   - Live synthetic image generation from configurable latent seeds ($\mathbf{z} \in \mathbb{R}^{100}$).
   - Download generated synthetic samples to test against the detector.
5. **Rigorous Evaluation Benchmarks:**
   - Held-out test split evaluation using scikit-learn.
   - Metrics: **Accuracy, Precision, Recall, F1 Score, ROC-AUC, and Confusion Matrix**.
6. **Verifiable Reporting:**
   - Export cryptographic inspection dossiers in **JSON** or publication-grade **PDF** format (via ReportLab).
7. **Privacy-First Local History:**
   - Optional SQLite database logging metadata and predictions without permanently retaining raw uploaded images.

## 🔬 Model & Preprocessing Specifications

- **Input Dimension:** $224 \times 224 \times 3$ RGB tensor.
- **Normalization:** ImageNet distribution ($\mu = [0.485, 0.456, 0.406]$, $\sigma = [0.229, 0.224, 0.225]$).
- **Architecture:** Hybrid Deep Forensic Network with deep convolutional representation stages, spatial pooling, and a calibrated linear classification head.
- **Explainability:** Grad-CAM hooks attached to the final convolutional feature extraction layer ($256$ feature channels).
- **Decision Bounds:**
  - $\text{AI Probability} \ge 0.60 \implies \textbf{Likely AI-Generated}$
  - $\text{AI Probability} \le 0.40 \implies \textbf{Likely Real (Camera-Captured)}$
  - $0.40 < \text{AI Probability} < 0.60 \implies \textbf{Inconclusive}$

## ⚖️ Ethical Considerations & Forensic Limitations

1. **Screening Tool, Not Proof:** Model outputs are mathematical probability estimates and should not be used as the sole basis for legal accusations or disciplinary actions.
2. **Compression Vulnerability:** Heavy JPEG compression (quality < 50) degrades subtle high-frequency forensic noise.
3. **Generative Shift:** Novel, unseen generative architectures may produce different artifact distributions than those present in training benchmarks.
4. **Hybrid Editing:** Real photos subjected to AI upscaling, generative inpainting, or background replacement exhibit mixed signals and are appropriately flagged as **Inconclusive**.
